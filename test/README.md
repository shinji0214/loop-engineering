# 凍結オラクル（test/）

このループを**自己改修させる**とき、各世代の出力が既存の振る舞いを壊していないかを
判定する外部の歯止め。ループ自身は生成・書き換えできない（人間が管理する）。

```bash
npm test                 # mocks/ + generations/ を実行
SLOW=1 npm test          # *.slow.*（レート制限テスト、~60秒）も含める
```

## 構成

| パス | 中身 | 実行方法 |
|---|---|---|
| `mocks/*.js` | `index.js` の挙動を検証する手書き統合テスト。オフラインのモック API サーバに `runLoop` を掛ける。exit 0 = pass | `node <file>` |
| `mocks/*.slow.*` | 実時間の待機を伴う遅いテスト（`SLOW=1` のときだけ実行）| 同上 |
| `generations/gen-NNN/` | 承認された世代が生成した受け入れテスト（`REQUIREMENTS.md` + `*.test.js`）。世代ごとに追加され、以降の全世代がこれに縛られる | `node --test` |
| `run.mjs` | 上記を全部走らせて集約。1つでも落ちたら exit 1 | — |

## 原則

- `mocks/` は**手書き**。ループに生成させない（GAN で D に本物データを見せるのと同じ役割）
- `generations/` への昇格は世代パイプラインが自動で行うが、**間違ったテストの混入**を防ぐため
  人間が時々 prune する
- 生成物（`logs/` `output/` `runs/` `.loop-tmp/`）は `LOOP_ARTIFACT_ROOT` で一時ディレクトリに
  隔離するので、テスト実行で本体を汚さない
